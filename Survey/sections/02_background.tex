In a standard Retrieval-Augmented Generation (RAG) pipeline, automated evaluation typically relies on the LLM-as-a-Judge paradigm. The baseline workflow is highly structured. The evaluating model receives a user query, the retrieved reference documents, and the target model's generated response. The model is then asked to score the response across specific dimensions, particularly verifying if the generated text is faithful to the provided context. While baseline LLM judges exhibit general vulnerabilities such as verbosity or self-enhancement biases \citep{wang2023fair}, applying this paradigm to dynamic RAG environments introduces a different set of domain-specific challenges. 

Overall, this survey adopts a unified view to explain how evaluation reliability is challenged under these RAG-specific pressures. One key issue is the ``internal fights'' within the model when its own parametric memory conflicts with the retrieved data. Finally, we demonstrate why the field must move toward ``Agent'' systems to resolve these systemic problems. 

To systematically analyze these issues, we categorize the research landscape into a three-branch taxonomy, as illustrated in Figure \ref{fig:taxonomy_tree}.

We organize our discussion around this structural map to track the complete lifecycle of evaluation:

\begin{itemize}
    \item \textbf{Section \ref{sec:triggers}} analyzes how noise and extreme context length trigger specific biases in LLM judges within the RAG environment. We evaluate how retrieved irrelevant information, such as distractors, systematically destroys the judge's evaluation capability.
    \item \textbf{Section \ref{sec:conflict}} provides a deep dive into the model's judging mechanisms when facing discrepancies between internal and external knowledge. We explore the aforementioned ``internal fights'' and define the paradox of knowledge conflict, synthesizing how researchers observe this struggle through internal probing and testing.
    \item \textbf{Section \ref{sec:mitigation}} collects current mitigation strategies and discusses the evolutionary trend toward ``Agent-as-a-Judge'' frameworks. We analyze the limitations of static interventions and show why the paradigm shift to multi-step, tool-augmented systems is necessary to fix these reliability issues.
\end{itemize}
